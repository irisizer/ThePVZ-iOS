# The PVZ — хоррор про ночную смену ПВЗ

Игра для iPhone (iOS 15+, только альбомная). Ты — работник ночной смены пункта выдачи. Обслуживай клиентов, сканируй накладные, вычисляй аномалий, вызывай ГБР.

## Геймплей (5 ночей)
- Каждая ночь: N клиентов (4/6/7/9/10), шанс аномалии растёт 25% → 45%.
- Клиент подходит к столу с QR-накладной (PVZ-XXXX-XXXX).
- Действия: **Сканировать** (2.5 сек, показывает ЧЕЛОВЕК/АНОМАЛИЯ), **Выдать**, **Отказ**, **ГБР** (едет 12 сек условно, в игре ~3 сек анимация).
- Верные решения:
  - человек + Выдать = обслужен
  - аномалия + Отказ/ГБР = нейтрализована
- Ошибки:
  - человек + Отказ/ГБР = жалоба
  - аномалия + Выдать = джампскейр, ночь провалена
- 3 жалобы = «Слишком много жалоб. Вы уволены.»
- Кнопка **Закрыть смену** активна осмысленно после обслуживания всех клиентов. Таймер ночи 150–240 сек.
- События: курьер (ночь 2, 30 сек), эмбиент-мигания каждые 18 сек, ГБР-отряд, джампскейр с вибрацией.

## Как собрать
1. Положи скриншот сайта (опционально) в `ThePVZ/Resources/Textures/pvz_screen.png` (1672×941). Без него будет процедурная заглушка.
2. Шрифты Gotham Pro (опционально) в `ThePVZ/Resources/Fonts/`. Без них — Montserrat → Avenir → системный.
3. Push в `main` → Actions → Build IPA → Artifacts → `.ipa`.
4. Релиз: `git tag v1.0.0 && git push --tags`.
5. Установка: Sideloadly / AltStore (IPA неподписанный).

## Отладка
- Тройной тап в игре = Debug-панель (fps, nodes).
- Тесты: Actions → Run workflow → run_tests=true, или локально `xcodebuild test`.
- Логи: `Log.info/warn/error` → NSLog.

## Структура
См. `project.yml` (XcodeGen), workflow `.github/workflows/build-ipa.yml`. `Support/Info.plist` генерируется XcodeGen, не коммитится.
